## 30 秒自检：是你的问题，还是墙的问题

先别急着卸载重装。对照下面这张表，大多数情况能马上分清：

| 你看到的现象 | 大概率原因 | 先做什么 |
|---|---|---|
| 关掉 VPN 后，国内网站也打不开 | 你自己的网络断了，跟墙无关 | 先修本地网络：重启路由器，或者换 4G/5G |
| 所有节点都连不上，群里也一片哀嚎 | 敏感期整体收紧 | 按下文「排查顺序」逐个试，先别换工具 |
| 只有部分节点连不上 | 这几个节点的 IP 被封了 | 换节点，优先试平时不用的地区 |
| 能连上，但网页极慢、视频卡住 | 国际出口被限速 | 换延迟低的节点，避开晚高峰 |
| 提示「证书错误」「握手失败」 | 系统时间不准，或者协议被识别 | 校准系统时间，换线路或协议模式 |
| 只有你连不上，朋友用同一个工具正常 | 地区或运营商差异 | Wi-Fi 和流量切换对比，换运营商网络试试 |

一个经验：**「全挂」和「部分挂」的处理方式完全不同。** 部分挂是常规封锁，换节点就行；全挂才是敏感期，这时候要做的是等和换线路，不是折腾设置。

## 为什么一到敏感期就集体连不上

平时的封锁像例行巡逻，敏感期像临时戒严。防火长城（GFW）在这些日子会切换到更严的模式，常见的手段有这么几种：

- **整段封 IP。** 平时是一个个点名封，敏感期会把可疑机房的整段 IP 一起拉黑。用公有云大段 IP 的国际大牌 VPN，往往第一批成片失效。
- **主动探测更频繁。** GFW 会主动去连可疑的服务器，试探它是不是代理。长期在线、IP 固定的节点最容易被标记。
- **协议识别更严。** 今年圈内普遍的观察是，OpenVPN、Trojan、VMess 这类老协议本来就容易被流量指纹认出来，敏感期门槛再一收，平时勉强能用的线路会直接失灵。
- **国际出口限速。** 不一定封死，而是让你连得上、用不动，QUIC/UDP 流量受影响尤其明显。
- **极端情况不能排除。** 2025 年 8 月 20 日，GFW 曾短时间对 443 端口做过无差别封禁（[GFW Report](https://gfw.report/zh/) 有完整分析）。443 是所有 HTTPS 网站用的端口，这说明「一夜全挂」在技术上完全做得到。

所以这份手册最重要的一句话是：**敏感期连不上，第一反应不该是「这个工具不行了」，而是「周期到了」。** 判断一个工具好不好，看它平时稳不稳、节后恢复快不快，别看敏感期当天。

## 连不上时的排查顺序

顺序很重要，前三步能解决大部分问题：

1. **换节点。** 敏感期通常是「部分节点死」，不是「全部死」。把节点列表从上到下多试几个，优先试平时不用的地区，比如香港换新加坡、日本换韩国。
2. **换线路或协议模式。** 正规客户端一般有「智能 / 备用线路」或者协议切换的开关。老协议被掐的时候，新协议的线路往往还活着。
3. **切换网络。** Wi-Fi 连不上就用 4G/5G 试一次，反过来也一样。三大运营商的封锁力度并不同步，电信收得最紧的时候，移动可能还能走。这一步也能帮你分清是工具的问题，还是网络出口的问题。
4. **校准系统时间。** 时间偏差大会导致加密握手失败，表现就是「证书错误」。手机和电脑都打开「自动设置时间」。
5. **排除本地干扰。** 关掉其他代理软件、广告拦截和各种「加速器」，它们可能在抢同一个系统 VPN 通道。
6. **看公告、找客服。** 去工具的官网或者客户端公告里看有没有维护通知。敏感期正规团队都在补线路，新线路一般先在公告或客服那里放出来。如果既没有公告渠道、客服也找不到人，那该考虑的就不是排查了，而是节后换工具。

## 分设备的小技巧

- **iPhone**：连不上的时候，先到「设置 - 通用 - VPN 与设备管理」里把旧的 VPN 配置删掉，再让 App 重新添加。iOS 偶尔会卡在旧配置上。
- **安卓**：华为、小米这些机型的省电策略会在后台杀掉 VPN 进程，表现就是「连着连着就断」。在电池设置里把 VPN App 设成不限制后台。
- **电脑**：浏览器里装的「翻墙插件」和客户端同时开，很容易互相冲突，敏感期只留一个。公司或学校的网络本身可能有额外限制，用手机热点对比一下就知道。

## 节前准备清单

敏感期自救，最好的办法是提前准备，而不是临时抢修。下面几件事十分钟做完：

- ☐ **把主力工具的时长充在节前。** 敏感期官网可能打不开，支付通道也可能不稳。买短期套餐就够，周卡正好覆盖长假。
- ☐ **领好免费额度。** 有签到送时长、注册送体验的工具，节前把额度领好。
- ☐ **备一个备胎，安装包提前下好。** 等全挂了，你连备胎的官网都打不开。
- ☐ **手机、电脑都装好、登录好。** 到时候哪台能连就用哪台。
- ☐ **要紧的事提前办。** 需要在国外平台提交的材料、要回的消息，尽量节前办完，别赌节中的网络。
- ☐ **收藏这一页。** 节中连不上的时候，按上面的排查顺序一步步来。

## 敏感期最不该做的五件事

- **反复卸载重装。** 解决不了封锁，反而可能把还能用的配置和缓存的线路清掉。
- **病急乱投医，去下「破解版」「免费加速器」。** 敏感期是钓鱼软件的收割季，搜索结果和群里冒出来的「敏感期专用」「永久免费」，不是后门就是骗局。
- **趁促销买年费。** 连运营多年、用户上千万的快连都在 2026 年 4 月退出了大陆，这一行的退出风险是真实存在的。永远先买周卡或月卡。
- **在最严的那几天换服务商。** 这几天所有家都在波动，你测不出任何一家的真实水平，等节后再比较。
- **在群里公开求「好用的梯子」。** 冒出来私聊你的，多数是倒卖机场订阅的，质量和售后都没保障。

平时挑工具看价格、看速度，敏感期只看三件事：**线路够不够多、断了能不能自己切过去、出问题能不能找到人。**

缺点也说清楚：冷门地区（南美、非洲）节点少；敏感期最严的时候它一样会波动，只是我这几年的体感是恢复得比较快。说到底，**不存在敏感期完全不受影响的工具，谁跟你保证「敏感期 100% 可用」，谁就在骗你。**

## 常见问题 FAQ

**Q：敏感期 VPN 全挂了，一般多久能恢复？**
A：经验是敏感日期前三到七天开始收紧，当天前后最严，之后几天到两周逐步回落。恢复得快慢，主要看工具方补线路的能力。

**Q：是所有 VPN 都会在敏感期出问题吗？**
A：几乎都会受影响，区别在程度和恢复速度。用公有云大段 IP、固定节点的国际大牌，通常最先成片失效。

**Q：连上了但是特别慢，正常吗？**
A：正常。敏感期除了直接封，还常见国际出口限速。换延迟低的节点，避开晚上八点到十一点的高峰，节后一般会恢复。

**Q：敏感期最容易踩的坑是什么？**
A：不是连不上，而是着急之下装了来路不明的「破解版」「免费加速器」，结果账号和隐私一起丢。只用正规渠道下载的工具。

**Q：用 ChatGPT、Claude 这类 AI 工具，敏感期要注意什么？**
A：AI 平台对 IP 地区和稳定性更敏感，敏感期来回换节点容易触发风控，尽量固定一两个地区的节点。更多细节见我的另一份手册：[在中国用 ChatGPT / Claude / Gemini](https://chinesevpn.github.io/chatgpt-vpn-guide/)。
